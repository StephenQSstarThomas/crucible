# P5-PANEL — 审稿人模拟与 rebuttal 就绪度

**判据**：把稿子交给四个带偏见的角色去读，预演真实评审会发生什么。

**产物不是 finding 列表，而是**：
1. 四份模拟审稿意见（含分数与 confidence）
2. 一张**弱点分诊表**：哪些截稿前能修、哪些只能在 rebuttal 里辩、哪些只能认
3. 每条预期 weakness 的预备回应

**默认 severity**：本 tier 不产生 blocker。它的输出是**优先级信息**，
用来决定剩余时间花在哪。

---

## 角色设置

四个角色**独立并行**运行，互相不可见（避免共识坍缩）。
每个角色只被给予论文 + 自己的 persona，不被给予前面 tier 的 findings——
否则会变成复述已知结论，失去独立信号。

| 角色 | 关注 | 典型开场白 |
|------|------|-----------|
| **AC (Area Chair)** | 显著性、venue 契合度、贡献是否清楚、能否进 program | "The paper is well-executed but I'm not sure it advances..." |
| **R1 方法学审稿人** | 实验设计、混杂、统计、可比性 | "The comparison in Table 2 is not apples-to-apples because..." |
| **R2 实证审稿人** | baseline 强度、ablation 充分性、复现性 | "Missing comparison against [obvious competitor]." |
| **R3 怀疑论者** | 主张是否过界、结论是否被数据支撑、有无 cherry-picking | "The claim of 'consistently outperforms' rests on N=8." |

四个角色与 P0–P4 的审查 agent 同批并行派发。它们不读 findings，所以不必等前面的层跑完。

---

## N1. 模拟意见的质量要求

| ID | 要求 |
|----|------|
| N1.1 | 每条 weakness 必须指向具体 `file:line` 或表格单元格 |
| N1.2 | 每条 weakness 必须说明"如果作者这样回应，我会不会被说服" |
| N1.3 | 给出分数时必须给出该分数的判据 |
| N1.4 | 必须至少列出 3 条 strength（只列缺点的审稿意见没有信息量） |
| N1.5 | 不得复述 P0–P4 已报告的机械缺陷（那些会被修掉） |
| N1.6 | 必须预测**审稿人会误解什么**，而不只是什么是错的 |

> N1.6 是本 tier 最有价值的一条。很多 weakness 的根源不是论文错了，
> 而是论文没有防住一个可预见的误读。例如 Table 2 各行分母不同这件事，
> 论文在正文里其实做了配对比较，但主表的呈现方式几乎保证审稿人会先误读、
> 后带着不满去找解释。**可预见的误读等价于缺陷**，因为修复责任在作者。

## N2. 弱点分诊

每条预测的 weakness 归入一档：

| 档 | 含义 | 行动 |
|----|------|------|
| **A — 截稿前可修** | 改写、补表、补说明即可消除 | 写进 REVISION_PLAN.md 的具体改法 |
| **B — 需补实验** | 需要跑新实验，时间够则修 | 估算成本，用户决策 |
| **C — 只能在 rebuttal 辩护** | 设计已定，但有合理理由 | 预写 rebuttal 段落 |
| **D — 只能认** | 真实局限 | 主动写进 limitations，抢在审稿人前面 |

> D 档的处理方式是本 tier 的一个具体建议：**主动承认的局限，
> 杀伤力远小于被审稿人抓出来的局限。** 把 D 档 weakness 提前写进
> limitations 一节，能把一条 weakness 变成一条 "authors are aware and honest"。

分诊表和 N3 的回应草稿由 `crucible-revision-planner` 写进 `REVISION_PLAN.md`，
与 P0–P4 的修改建议放在同一份清单里、但单独成节。

## N3. Rebuttal 预备

对每条 A/B/C 档 weakness，产出：

- **预期审稿人措辞**（审稿人大概会怎么写这条）
- **回应草稿**（英文，可直接改用）
- **回应所需的证据**（哪张表、哪个补充实验、哪段文献）
- **该证据现在有没有**（有 → 只需指路；没有 → 进 B 档）

## N4. 分数校准

模拟分数**不作为质量背书**使用，只用于内部排序。报告中必须标注：

> 模拟分数由语言模型产生，与真实审稿分数的相关性未经验证。
> 它的用途是给弱点排序，不是预测录用结果。

| ID | 要求 |
|----|------|
| N4.1 | 四个角色的分数分别报告，不取平均 |
| N4.2 | 分歧点单独列出（分歧本身是信息：说明该处依赖主观判断） |
| N4.3 | 不输出"接收概率" |

> N4.3 的理由：给出一个"68% 接收概率"会让作者据此做决策，
> 而这个数字没有任何校准依据。CRUCIBLE 宁可不给数字，
> 也不给一个看起来精确、实则凭空的数字——这与它审查论文时用的是同一条标准。

## N5. 与前序 tier 的关系

P5 是**唯一允许提出主观意见**的 tier。P0–P4 的每条 finding 都必须可复算、
可定位、可对抗验证；P5 的输出明确标注为**预测**，与事实性 finding 在报告中
分区呈现，不混排。

这条边界必须守住。一旦把"我觉得 novelty 不够"和"表 3 的算术对不上"
放进同一个列表，前者会稀释后者的可信度。
