# A-AUTHORSHIP — 写作来源三档判断

本层回答一个受限问题：现有证据更符合“人类主导”“AI 深度参与”还是“全 AI”。
它不是 finding tier，不影响 P0–P5 severity，也不是对作者诚信的指控。

## 固定输出档位

只能选择一个：

| 档位 | 判据 |
|------|------|
| **人类主导** | 现有直接证据显示 AI 仅用于局部语言帮助，或没有足够证据支持更高档；可有人工修订轨迹。这里不是“证明没有用 AI”。 |
| **AI深度参与** | 有直接披露或多条独立证据表明 AI 参与了大段 drafting、rewriting、结构组织或跨章节文本生成，但没有充分依据认定几乎全文由 AI 生成。 |
| **全AI** | 有可信的直接 provenance 明确说明几乎全文生成，或全文范围内存在多条相互独立且高特异性的生成证据。仅凭流畅、套话、破折号、词频或 detector 分数不得使用本档。 |

## 证据优先级

从强到弱综合：

1. 作者明确的 AI-use statement、生成记录、可核验的写作日志或版本 provenance。
2. 源码中高特异性泄漏，如未清理的 assistant 自述、聊天角色标记、生成指令、占位引用。
3. 可定位到多个章节的事实性 hallucination、引用不存在、内部矛盾与模板残留。它们首先是论文缺陷，只能作为辅助信号，不能单独证明来源。
4. Git/修订轨迹、注释和 change-tracking。它们可证明有人编辑过，但不能证明文本最初由谁写。
5. Stylometry、句长、词汇分布、常见“AI 味”表达。仅作弱背景，绝不能单独升级档位。

## 必查的反证

- AI 工具名称可能是论文研究对象，不是写作披露。
- 一份 disclosure 可能只承认 grammar polishing，不代表深度参与。
- 没有 Git 历史通常只是 arXiv source package 丢失历史。
- 引用错误、措辞整齐、章节同质也会出现在人类写作中。
- 人类大幅修改 AI 初稿与 AI 大幅改写人类初稿通常无法仅从终稿区分；证据不足时不得写成事实。

## 输出纪律

- 不给百分比，不伪造统计校准；只给上述三档。
- 每个支持或反对信号都必须引用 `file:line` 或 facts 字段。
- 明确列出 `unavailable_evidence`，说明 source/PDF/Git/history 的缺失。
- 结论措辞固定为“当前可得证据更符合……”，不得写“作者一定……”或“检测证明……”。
- 若只能看到 PDF，必须说明无法可靠区分“人类主导”和“AI 深度参与”；仍需给一档时选最符合现有证据者并保留限制说明。
