# Empiricist simulation

**总体判断**：比只给成功 demo 强，但 runtime 与 capability coverage 仍小，closest public system 没有直接比较。

**Strengths**：外部 deterministic scorer；公开代码；boundary class；439/440 model-free tests 可在独立 Linux 环境跑通。

**Weaknesses**：四个主 family；runtime 4/7；energy/UFO/MA5 各 2 cases；没有 HEPTAPOD/MadAgents shared-task baseline。

**最可能要求**：family-level results、case artifacts、至少一个最近邻共同请求或不可比说明。
