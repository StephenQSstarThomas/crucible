# Methodologist simulation

**总体判断**：paired replay 设计合理，但报告了多个不同 estimand，headline 主要突出最有利的 conditional normalized rate。

**Strengths**：B/C 共用同一 response；transitions 完整闭合；infrastructure failures 被单列而非伪装成 semantic failures。

**Weaknesses**：47/60 conditioning；四个 workflow family × paraphrases 的 cluster 结构未展开；scorer correction 未实际重算；severity rubric 缺失。

**最可能要求**：availability/conditional/planned-case 三联表，per-family sensitivity，v1.2.1 rescore。
